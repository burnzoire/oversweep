# Editorial review — Airfield and ATC terms

- Source: `content/encyclopedia/terminology/airfield-atc.md`
- Reviewed: 2026-11-02
- Scope: Inspected glossary terms and reference structure, without rendering the site or independent SME validation
- Scope: 72 glossary entries

## 1. Is it too long?

Long due to 72 reference definitions. Prioritise easy navigation and keep the full terminology, but avoid repeating complete procedures where the airfield operations and radio modules already teach them.

## 2. Imagery and interactivity

Term-focused lookup works better than images; pronunciation/audio can help only where clear radio learning outcomes justify it. The main airfield module already has diagrams.

## 3. Learning outcomes

Identify pattern legs, taxi/hold terms, tower instructions, runway lighting and airfield movement vocabulary.

For a terminology page the outcome is rapid, correct recognition and disambiguation, not completion of a narrative lesson.

## 4. Missing important information

Distinguish civil FAA terms from US military service-specific use. Date-sensitive definitions (ATIS, MARSA, runway signage) need edition and jurisdiction.

## 5. Simulator relevance and differences

DCS/BMS ATC may support only subsets of real-world calls and airport signs/lights. Distinguish real terminology from sim menu calls and nonfunctional services.

Explain applicability to specific simulator/module/version only where verified. Classify implemented, simplified, unavailable or unverified, and keep documented real-world terminology distinct from simulation features. Use existing sim-panel styling where applicable.

## Recommended action

Improve term discoverability, usage context and cross-links before trimming authoritative definitions. SME source review remains required for doctrinal changes.

**Applied (record revision, 2026-11-05):** the set now links the Airfield Operations and Radio Communications modules. The civil/military split, the service marks and the ICAO differences were already in the intro. No sim note: no sim source was read for these words.
